# Screenshots

Drop project screenshots/GIFs here, then reference them from the root `README.md`.

Suggested files (rename as you like):

- `landing.png` — public marketing landing page
- `admin-dashboard.png` — institute admin dashboard
- `test-editor.png` — test editor with sections / question bank
- `take-test.png` — student take-test view (timer + sections)
- `result.png` — auto-graded result breakdown
- `leaderboard.png` — per-batch leaderboard
- `dark-mode.png` — dark mode enabled

Tips:
- Keep each image under ~500 KB, 1200–1600px wide.
- A short GIF of the take-test flow (record with ScreenToGif or Win+G) makes a great hero image.

Reference them from the root README like:

```markdown
![Landing page](docs/screenshots/landing.png)
<img src="docs/screenshots/take-test.png" alt="Take test" width="700" />
```
